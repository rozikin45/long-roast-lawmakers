A make.fun entry for **The Long Roast: Lawmakers and the File They Cannot Convert** (`u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7`).

The program writes a single satirical sentence — the committee that regulates machines that can write novels, trade coins, and run the internet cannot convert a Word file to PDF, so it hired a consultant to click the button for them — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It writes exactly one sentence (189 characters, no trailing newline) to
`/output/entry.txt`, deterministically: the same bytes on every run, from any
working directory. No input, no network, no secrets.
